# Add Tsuikabako to Kurobayomi

You need [Kurobayomi](https://github.com/kurobayomi/kurobayomi) installed. Then either click **Add to Kurobayomi**, which
opens the app with the address filled in so you only confirm, or copy the address and add it yourself.

<AddButtons />

## By hand

1. Open Kurobayomi and click **Add a source repository** on the welcome screen. Once you have a repository, the same is
   in **Settings → Sources and tracking → Repositories**, behind **Add**.
2. Paste the address above.
3. Click **Add**.

Kurobayomi then lets you pick the sources to turn on; you can change them later in Browse. Kurobayomi checks the repository at every start, so new
sources and fixes come by themselves.
